# Al-Shifa Diagnostic Centre — Hospital Management System

A full-featured, offline-first hospital management desktop application built for Al-Shifa Diagnostic Centre.

## Built With
- **Frontend:** React + Tailwind CSS (Vite)
- **Backend:** Node.js + Express
- **Database:** SQLite via Prisma ORM
- **Desktop:** Electron (cross-platform Windows + Linux + Mac)

## Features
- 👥 Patient registration with unique ID (ASD-0001) and full history
- 🏥 OPD queue management with token system
- 🛏️ Patient admission, room & bed management
- 👨‍⚕️ Doctor management with weekly schedules
- 💊 Prescription module with bilingual (English/Urdu) medicine dosage
- 🔬 Lab invoicing and results entry with abnormal value detection
- 💰 Pharmacy inventory and invoicing
- 🧾 Discharge billing with itemized breakdown
- 📊 Admin dashboard with live stats and revenue charts
- 🔐 Role-based access (Admin, Doctor, Receptionist, Lab Assistant)
- 📄 Print and PDF export for prescriptions, lab reports, invoices
- 📱 WhatsApp sharing for lab reports and prescriptions
